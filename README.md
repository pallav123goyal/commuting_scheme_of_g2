This repository gives all the Macaulay2 codes used in the paper: https://arxiv.org/abs/2610.05018. The following is a list of files in this repository, the result proven using that file and their approximate runtimes:

1) system_of_parameters.m2 - Proposition 4.1 - 5 seconds
2) affine_fiber.m2 - Proposition 4.7 - 25 seconds
3) primes_till_1000 - Proposition 5.3 - 550 seconds
4) char3.m2 - Proposition 5.4 - 350 seconds
5) char2_Hilbert.m2 - Lemma 5.12 - 360 seconds
6) char2_reduced.m2 - Lemma 5.14 - 1 second
7) degree_comp.py - Generate Table 2 - 80 seconds
